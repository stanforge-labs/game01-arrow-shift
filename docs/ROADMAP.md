# Roadmap

Current stage: product shell with Home, Levels and Game navigation, local unlock progression, procedural tactile SFX, Route and Rush modes.

Gameplay content is frozen: Puzzle (30 levels), Route (12 levels) and Rush (24 validated templates) are gameplay-complete. Procedural SFX and quiet ambient music are complete. Further work is limited to bug fixes, moderation fixes, SDK integration and release assets. The next approved stage is a separate Yandex Games SDK integration review; ads, shop, achievements, currency, skins and backend remain out of scope.
