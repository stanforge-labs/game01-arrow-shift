# Yandex Games moderation notes

- Current build is a local-only prototype: no Yandex Games SDK, ads, purchases, analytics, external requests or accounts.
- All gameplay content is original SVG/CSS geometry and authored level data; no third-party images, music or icon packs are bundled.
- Controls are keyboard, mouse and touch accessible. Sound starts after interaction and can be disabled.
- Puzzle, Route and Rush are self-contained in-app modes with no deceptive UI, forced redirects or hidden downloads.
- Add official SDK and platform lifecycle handling only as a separately reviewed stage.
