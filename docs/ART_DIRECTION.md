# Art direction

Calm modern casual puzzle: warm paper-like background, soft tactile tiles, compact centered mobile canvas. Original arrows are CSS geometry, never emoji or copied art.

| Token | Value |
| --- | --- |
| background | `#f5f0e7` |
| surface | `#fffdf8` |
| surface-soft | `#f8f4ec` |
| board | `#ebe5db` |
| board-grid | `rgb(67 68 60 / 3.5%)` |
| text | `#2c302d` |
| arrow | `#303632` |
| accent | `#4f7b6a` |
| success | `#48795e` |
| danger | `#a8574c` |
| radius | `24px` |
| shadow | `0 18px 42px rgb(61 51 38 / 13%)` |
| board size | `min(100%, 520px)` |
| spacing | `16px` base |

Motion is short, legible and disabled to near-instant under `prefers-reduced-motion`.
