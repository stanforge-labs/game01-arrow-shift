# Arrow Shift agent guide

- This is a personal, mobile-first game project. Use Vite with vanilla JavaScript, HTML, CSS and SVG/CSS geometry.
- Keep the MVP small, playable and tested; do not start a larger product stage without the owner's approval.
- Do not copy other games, source code, levels, UI, text or assets. Use references only for broad UX learning.
- Keep dependencies minimal and justified. Do not add trackers, secrets, CDN assets, suspicious licences or AI-looking art.
- Test meaningful changes, including the pure game logic and the real UI with the configured Playwright/Yandex Browser setup.
- Do not ask the owner to perform work an agent can safely do itself.
- Keep the short documents in `docs/` accurate: `GAME_SPEC.md` is the primary source of truth.
